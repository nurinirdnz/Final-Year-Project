# User Stories

1. As an environment officer, I want to see all current hotspots on a map, so that I know where fires are burning near Sarawak.
2. As an environment officer, I want each hotspot labelled as a persistent fire or a short-lived detection, so that I can ignore brief detections.
3. As a disaster management officer, I want a next-day haze forecast for each monitoring station, so that I can warn the public early.
4. As a fire and rescue officer, I want hotspots ranked from most to least dangerous, so that I know which fires to check first.
5. As a dashboard user, I want the dashboard to update by itself, so that I always see the latest situation.
