# User stories

## US1 (links to FR3)
As a fire and rescue officer, I want to see hotspots ranked by haze risk, so that I can decide which fires to check first.

Acceptance criteria:
1. The list is sorted from highest to lowest risk.
2. Each item shows its class and its distance to Sarawak.
3. Tapping an item centres the map on that hotspot.

## US2 (links to FR4)
As a parent in Kuching, I want to see whether tomorrow's air will be unhealthy at my nearest station, so that I can prepare my family.

Acceptance criteria:
1. Choosing a station shows Yes or No for API above 100.
2. The screen shows when the forecast was made.

## US3 (links to FR5)
As a resident, I want to see hotspots near my location, so that I know whether a fire is close to me.

Acceptance criteria:
1. With GPS permission, only hotspots inside the chosen distance are listed.
2. If permission is refused, the app shows a message and the full map.
